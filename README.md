## 📚 Sobre este repositório

Repositório dedicado ao estudo dos **fundamentos da AWS**, visando a preparação para certificações.

Contém anotações, conceitos essenciais e documentação prática de **labs** realizados para reforçar o aprendizado.

---

## ⚙️ O que são os labs e qual a sua importância?

**Labs** são exercícios práticos que simulam cenários reais na AWS, possibilitando a experimentação dos serviços e aplicação dos conceitos estudados.

Esses exercícios contribuem para:

- Fixação dos conceitos  
- Compreensão dos fluxos de uso dos serviços  
- Desenvolvimento de confiança para a certificação e mercado de trabalho  

---

## 🚀 Objetivo

Consolidar conhecimentos teóricos e práticos para a certificação, estabelecendo uma base sólida em computação em nuvem e serviços AWS.
